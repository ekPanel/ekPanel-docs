## ekPanel কি production-এর জন্য তৈরি?

**এখনো না।** ekPanel শুরুর দিকের development-এ আছে। এর প্রথম release, **v0.1.0**, বের হয়েছে
9 November 2026-এ। এই docs-এ যা কিছু
বলা আছে সব কাজ করে আর একটা test server-এ (একটা local virtual machine) test করা হয়েছে, কিন্তু এটা
এখনো আসল customer-দের জন্য আসল hosting চালায়নি। কিছু অংশ কখনো আসল বাইরের service-এর সাথে চেষ্টা
করা হয়নি: Cloudflare-এর API test করা হয়েছে তার একটা নকল copy-র সাথে, আর internet-এ mail পাঠানো ও
internet থেকে mail আসা দিয়ে email চেষ্টা করা হয়নি।

এটা দিয়ে জিনিস চেষ্টা করে দেখুন, test করুন, আর সমস্যা খুঁজে পেতে আমাদের সাহায্য করুন। এখনই এতে
গুরুত্বপূর্ণ কিছু host করবেন না। এক command-এই আপনি [এটা install করতে](/start/install/) পারেন, আর
panel থেকেই এটা নিজেকে update করে। দেখুন [roadmap](/project/roadmap/)।

## "ek" মানে কী?

*ek* (এক) বাংলায় "এক": আপনার পুরো hosting-এর জন্য একটাই panel। নামটা লিখুন **ekPanel**, ছোট e
আর বড় P দিয়ে।

## এটা কোন operating system-এ চলে?

Installer গ্রহণ করে **Ubuntu 24.04 বা তার নতুন** (24.04, 24.10, 25.x, 26.x) আর **Debian 12 বা 13**,
**amd64** (x86_64) বা **arm64** (aarch64) processor-এ। এর জন্য একটা নতুন server লাগে, root হিসেবে।

এখন পর্যন্ত test হয়েছে Ubuntu 24.04-এ। অন্য Linux distribution (AlmaLinux, Rocky Linux…) এখনো
support করা হয় না। দেখুন [Requirements](/start/requirements/)।

## Docker কি লাগবে?

**না।** Panel, agent আর website (static, PHP, WordPress) Docker ছাড়াই চলে। কোনো server-এ আপনার
প্রথম Docker app, Git app বা catalogue service যোগ করলে agent সেখানে distribution-এর package থেকে
Docker install করে। যে server-এ app নেই, সেখানে কখনো Docker আসে না।

Development-এর জন্যও Docker লাগে না: `make dev` নিজের embedded PostgreSQL চালু করে।

## এটা কি Cloudflare-এর সাথে ব্যবহার করা যায়?

**হ্যাঁ, আর DNS চালানোর জন্য এটাই পরামর্শ দেওয়া উপায়।** একটা API token দিয়ে আপনার Cloudflare
account connect করুন, তাহলে প্রতিটা website আর app-এর DNS record Cloudflare-এ তৈরি হয় আর sync-এ
থাকে। প্রতিটা record-এর জন্য আলাদা করে Cloudflare-এর proxy চালু বা বন্ধ করা যায়। Proxy-এর পেছনে
থাকলেও ekPanel-এর log, traffic chart আর CrowdSec ban visitor-দের আসল address দেখে (Caddy
`CF-Connecting-IP` header বিশ্বাস করে শুধু Cloudflare-এর নিজের address থেকে এলে)।

দুটো জিনিস জেনে রাখুন:

- এটা Cloudflare-এর API-এর একটা নকল copy-র সাথে test করা হয়েছে, এখনো আসলটার সাথে নয়।
- Cloudflare-এর proxy-এর পেছনে, CrowdSec ban শুধু তাদেরই থামায় যারা সরাসরি আপনার server-এ আসে।
  Cloudflare-এর মধ্য দিয়ে আসা request আসে Cloudflare-এর address থেকে, যা ekPanel কখনো ban করে না।

দেখুন [Cloudflare DNS](/guides/dns/cloudflare/)।

## Cloudflare ছাড়া কি এটা ব্যবহার করা যায়?

হ্যাঁ। যেকোনো DNS host-এ আপনার domain-গুলো আপনার server-এর দিকে point করুন, অথবা ekPanel দিয়ে নিজের
name server চালান (PowerDNS, DNSSEC-সহ)। দেখুন [নিজের name server](/guides/dns/name-servers/)।

## এটা কি free? Licence কী করতে দেয়?

ekPanel হলো **GNU Affero General Public License v3.0**-এর (`AGPL-3.0-only`) অধীনে free software।
আপনি এটা যেকোনো কাজে ব্যবহার করতে পারেন, commercial hosting-সহ, আর এটা পড়ে বুঝতে, বদলাতে আর
শেয়ার করতে পারেন।

AGPL-এর একটাই বাড়তি নিয়ম: আপনি যদি ekPanel-এর একটা **বদলানো** version অন্য মানুষের জন্য service
হিসেবে চালান (যেমন, আপনার customer-রা এতে sign in করে), তাহলে ওই মানুষদের আপনার বদলানো version-এর
source code একই licence-এ দেওয়ার ব্যবস্থা রাখতে হবে। না বদলে চালালে কিছুই করতে হয় না।
দেখুন [Licence](/project/license/)।

## এটা কোন কোন ভাষায় কথা বলে?

Panel আছে **English** আর **বাংলা**-য়, দুটোই সম্পূর্ণ। প্রত্যেকে notification পান নিজের ভাষায়।
UI Arabic-এর মতো ডান-থেকে-বাম ভাষার জন্য তৈরি, আর নতুন ভাষা মানে সাধারণ JSON file। দেখুন
[অনুবাদ](/development/translating/)।

এই docs-ও English আর বাংলায় আছে।

## cPanel, aaPanel বা Coolify থেকে এটা কীভাবে আলাদা?

ওই panel-গুলো যা করে, ekPanel তা এক জায়গায় এনেছে:

- **Classic web hosting**, cPanel আর aaPanel-এর মতো: পাশাপাশি একাধিক version-সহ PHP website, একটা
  file manager, SFTP আর FTP, database, email, DNS, WordPress tool, backup।
- **App deployment**, Coolify-এর মতো: Docker image, Compose file, zero-downtime release-সহ Git
  deploy, rollback আর pull request preview, আর এক-click service-এর একটা catalogue।

অন্যান্য পার্থক্য:

- এটা open source (AGPL), আর কোনো paid edition নেই।
- একটা panel **অনেক server** manage করে। প্রতিটা server-এ একটা ছোট agent চলে যা বাইরের দিকে panel-এ
  connect করে, তাই NAT-এর পেছনের server-ও কাজ করে।
- Panel প্রতিটা website আর app-এর **desired state** মনে রাখে; agent server-কে সেটার সাথে মিলিয়ে নেয়
  আর গরমিল (drift) নিজেই ঠিক করে। দেখুন [Desired state](/concepts/desired-state/)।
- Agent শুধু একটা নির্দিষ্ট তালিকার **typed operation** গ্রহণ করে। যেকোনো shell command চালায় এমন
  কোনো endpoint নেই।
- এটা শুরু থেকেই অনেক ভাষার জন্য বানানো।

cPanel-এর তুলনায় এতে এখনো যা **নেই**: reseller, cPanel backup-এর importer, একটা WAF, আর billing integration। এগুলো
আছে [phase 4](/project/roadmap/)-এ। Server-এর মধ্যে website, app, database আর পুরো customer সরানো আসছে পরের release-এ।

## এটা দিয়ে কি hosting বিক্রি করা যায়?

আপনি **customer**-দের **package**-সহ তাদের নিজস্ব account দিতে পারেন: website, database, app, disk,
memory আর CPU-এর সীমা (memory আর CPU kernel মানতে বাধ্য করে), PHP version, server, email আর FTP।
Customer-রা একই panel-এ sign in করে আর শুধু নিজেদের জিনিসই দেখে।

এখনো নেই: reseller account, white-label branding, customer suspend করা, bandwidth-এর সীমা, আর billing
integration (WHMCS, Blesta, Paymenter)। আর ekPanel এখনো শুরুর দিকের software, তাই আজ এটা দিয়ে
hosting বিক্রি করবেন না। দেখুন [Customer আর package](/guides/admin/customers/)।

## cPanel বা অন্য panel থেকে কি site import করা যায়?

এখনো না। cPanel backup, aaPanel আর Coolify-এর importer phase 4d-তে আসার plan আছে। আজকের দিনে আপনি
একটা website যোগ করে file manager বা SFTP দিয়ে এর file upload করতে পারেন, আর আপনার চেনা tool দিয়ে
database import করতে পারেন।

## এটা কি বাইরে তথ্য পাঠায় (phone home)?

কোনো telemetry নেই: ekPanel আপনার সম্পর্কে project-কে কিছুই জানায় না। Panel বাইরের service-এর সাথে
যোগাযোগ করে শুধু আপনার set up করা feature-এর জন্য, যেমন Cloudflare-এর API বা আপনার notification
channel (Telegram, Discord, Slack, webhook, আপনার SMTP server)।

Server-গুলো যা install করে তা download করে সাধারণ জায়গা থেকে: distribution-এর package mirror,
Caddy-র, CrowdSec-এর আর PHP-এর package repository, WP-CLI, Railpack আর Stalwart-এর মতো tool-এর জন্য
project-গুলোর নিজস্ব release page (প্রতিটা তার প্রকাশিত checksum-এর সাথে মিলিয়ে দেখা হয়), আর
country blocking ব্যবহার করলে মাসে একবার DB-IP-এর country list। Panel-এর font self-hosted, তাই এটা
font CDN-এ call করে না।

Release থেকে install করা panel প্রতি 6 ঘণ্টায় ekPanel-এর নতুন release-ও খোঁজে। এটা GitHub-এর release
page থেকে ছোট একটা file (`release.json`) download করে; এই request-এ আপনার panel-এর version বা অন্য কোনো
তথ্য যায় না। `EKPANEL_UPDATE_CHECK=false` দিলে এটা বন্ধ হয় (দেখুন [আপডেট](/guides/admin/updates/))।
Update নিজেও একই জায়গা থেকে release download করে।

## আমার data কোথায় থাকে?

আপনার server-এ। Panel-এর database হলো panel-এর server-এ PostgreSQL; website, database, mail আর
backup থাকে আপনার manage করা server-গুলোতে (অথবা backup-এর ক্ষেত্রে আপনার নিজের S3-compatible
storage-এ)। দেখুন [Port আর path](/reference/ports-and-paths/)।
