Main repository-তে আছে panel, agent, web UI, installer আর test VM script, সব `ekpanel` নামের একটা Go
module-এ। এই page একটা map: প্রতিটা folder কী, আর কিছু বদলাতে চাইলে কোথায় দেখবেন।

## Top level

<FileTree>

- .github/workflows/ci.yml CI: Go check আর test, UI typecheck, অনুবাদ, build
- .github/workflows/release.yml vX.Y.Z tag-এর জন্য release build, sign আর publish করে
- assets/brand/ logo file আর সেগুলোর নিয়ম (README.md)
- cmd/
  - ekpanel/ panel program
  - ekpanel-agent/ agent program
- deploy/
  - install.sh নতুন Ubuntu বা Debian server-এর installer
- docs/
  - TRANSLATING.md UI কীভাবে অনুবাদ করবেন
- internal/ সব Go package (নিচে দেখুন)
- scripts/
  - release-notes.sh CHANGELOG.md থেকে একটা version-এর release notes
  - test-vm.sh ফেলে দেওয়ার মতো Ubuntu test VM
- web/ React আর TypeScript UI
- CONTRIBUTING.md
- LICENSE AGPL-3.0
- Makefile build, test আর dev-এর কাজ
- PLAN.md master plan আর প্রতিটা phase-এর অগ্রগতি
- README.md
- SECURITY.md security policy আর design-এর নীতি
- go.mod

</FileTree>

`bin/`, `dist/` আর `.data/` (development database) `make` বানায়, আর এগুলো Git-এ নেই।

## দুটো program

| Folder | Program | `main.go` কী করে |
| --- | --- | --- |
| `cmd/ekpanel` | `ekpanel` | Configuration load করে, database খোলে আর migrate করে, agent CA বানায়, task runner, notifier আর cleanup loop চালু করে, তারপর web UI আর API, আর agent listener serve করে। এতে `version` আর `add-server` command-ও আছে। |
| `cmd/ekpanel-agent` | `ekpanel-agent` | `enroll`, `run`, `version`, আর internal `files` worker। |

## `internal/`-এর Go package

প্রতিটা লাইন package-এর নিজের doc comment থেকে নেওয়া।

| Package | এটা কী |
| --- | --- |
| `agent` | Server-এর দিকের agent: Linux থেকে fact আর metric জোগাড় করে, panel-এ stream করে, আর panel-এর typed operation কার্যকর করে। প্রতিটা area-র জন্য একটা file: `sites.go`, `fpm.go`, `databases.go`, `apps.go`, `builds.go`, `backup.go`, `firewall.go`, `mail.go`, `nameserver.go`, `ftp.go`, `malware.go`, `countries.go`, `security.go`, `wordpress.go`, `wptoolkit.go`, `terminal.go`… |
| `agentproto` | Panel আর agent-এর মধ্যে আদান-প্রদান হওয়া message: enrolment আর connect path, operation-এর নাম, আর প্রতিটা spec আর result type। |
| `api` | Panel-এর HTTP layer: `/api/v1`-এর নিচে JSON API, agent endpoint আর embed করা web UI। `server.go`-তে প্রতিটা route-এর list আছে। |
| `auth` | Password hashing (argon2id), random token আর TOTP helper। |
| `catalog` | One-click service: project-এর review করা Compose file (`templates/<id>.yaml`), প্রতিটার দরকারি variable-সহ। |
| `cloudflare` | Cloudflare-এর API-এর যে অংশ ekPanel ব্যবহার করে: zone, DNS record, SSL mode আর cache purge। `cloudflaretest/`-এ test আর local ব্যবহারের জন্য একটা fake Cloudflare আছে। |
| `config` | Flag আর `EKPANEL_*` environment variable থেকে panel-এর settings load করে। |
| `cron` | পাঁচ-field-এর cron schedule পড়ে, পরের run-এর সময় বের করে, আর সেগুলো systemd `OnCalendar` expression হিসেবে লেখে। Panel আর agent দুটোই ব্যবহার করে। |
| `db` | PostgreSQL pool খোলে আর embed করা schema migration (`migrations/*.sql`) apply করে। Embedded development database-ও এখানে। |
| `dnssync` | ঠিক করে কীভাবে একটা Cloudflare zone-কে ekPanel-এর চাওয়া record-এ আনা যায়, শুধু সেই record বদলে যেগুলো এটা বানিয়েছে আর তারপর কেউ বদলায়নি। |
| `hub` | Connect থাকা server-গুলোর live state (online status, সাম্প্রতিক metric), browser-গুলোতে fan-out, আর agent-এ operation routing। |
| `notify` | Notification: panel-এর inbox আর channel (email, Telegram, Discord, Slack, webhook), প্রতিটা user-এর ভাষায় (`locales/`)। |
| `pki` | Agent connection-এর জন্য panel-এর private certificate authority। |
| `release` | ekPanel-এর release খোঁজে, download করে আর check করে: sign করা `SHA256SUMS`, archive, আর version তুলনা। `release.pub` হলো release sign করার key। |
| `secretbox` | Panel-কে যে ছোট secret আবার ব্যবহার করতে হয় সেগুলো encrypt করে, যাতে শুধু database-এর একটা copy থেকে সেগুলো জানা না যায়। |
| `store` | PostgreSQL-এর ওপর data access layer: প্রতিটা area-র জন্য একটা file (`sites.go`, `apps.go`, `customers.go`…)। |
| `tasks` | `tasks` table-এ রাখা background কাজ: যা কিছু ধীর, আর যা কিছু agent-কে server বদলাতে বলে। এতে সেই reconcile-ও আছে যা একটা server-এর desired state বানায়, আর self-update (`update.go`)। |
| `updates` | ekPanel-এর নতুন release খোঁজে আর administrator-দের সে খবর দেয়। |
| `webui` | Build করা web app embed করে। `make ui` `web/dist`-কে `internal/webui/dist`-এ copy করে। |

### Migration

`internal/db/migrations/`-এ `0001_init.sql` থেকে (আজকের হিসেবে) `0029_updates.sql` নামের SQL file আছে।
Panel চালু হওয়ার সময় নতুনগুলো নামের ক্রমে apply করে। পরের number দিয়ে একটা নতুন file যোগ করুন; যেটা আগেই
`dev`-এ আছে সেটা কখনো বদলাবেন না।

## `web/`-এর web UI

<FileTree>

- web/
  - index.html
  - package.json script: dev, build, typecheck, i18n:check
  - vite.config.ts panel-এর দিকে dev proxy, build settings
  - public/
    - favicon.svg
    - theme-init.js app load হওয়ার আগে theme আর ভাষা set করে
  - scripts/
    - check-i18n.mjs বাকি আর অব্যবহৃত translation key খুঁজে বের করে
  - src/
    - main.tsx route আর app-এর শুরু
    - index.css Tailwind আর theme-এর রং
    - components/ কয়েকটা page-এ ব্যবহৃত card আর widget
      - ui/index.tsx button, input, dialog, badge…
    - i18n/
      - index.ts ভাষা আর i18next setup
      - locales/
        - en.json English, source ভাষা
        - bn.json বাংলা
    - lib/
      - api.ts API client আর API-এর উত্তরের TypeScript type
      - format.ts Intl দিয়ে number, size আর date
      - live.ts live server statistics
      - session.ts sign-in করা user
      - theme.ts light, dark বা system theme
    - pages/ প্রতিটা page-এর জন্য একটা file, যেমন SitesPage.tsx আর SiteDetailPage.tsx

UI ব্যবহার করে React, TypeScript, Vite, Tailwind CSS, TanStack Query, React Router, i18next, lucide icon,
CodeMirror (file manager-এর editor) আর xterm.js (terminal)। Font হলো self-hosted Noto Sans, Noto Sans Bengali
আর JetBrains Mono।

## কী বদলাতে কোথায় দেখবেন

| আপনি চান… | দেখুন |
| --- | --- |
| একটা API endpoint যোগ করতে বা বদলাতে | `internal/api/server.go` (route), `internal/api/`-এ একটা handler file, তার পাশে একটা test |
| কী store হয় তা বদলাতে | `internal/db/migrations/`-এ একটা নতুন migration, তারপর `internal/store/` |
| Server-এ কী হয় তা বদলাতে | `internal/agentproto/` (spec), `internal/agent/` (কাজ), `internal/tasks/tasks.go` (panel কী পাঠায়) |
| একটা one-click service যোগ করতে | `internal/catalog/templates/<id>.yaml` আর `internal/catalog/catalog.go` |
| একটা page বা card বদলাতে | `web/src/pages/` বা `web/src/components/` |
| UI text বদলাতে বা যোগ করতে | `web/src/i18n/locales/en.json` (আর `bn.json`) |
| একটা notification-এর text বদলাতে | `internal/notify/locales/en.json` (আর `bn.json`) |
| Installer বদলাতে | `deploy/install.sh`, তারপর [test VM](/development/test-vm/)-এ test করুন |
| Sign-in, session, role বদলাতে | `internal/api/auth.go`, `internal/auth/` |
| Panel-এর settings বদলাতে | `internal/config/config.go` |

একটা আসল feature দিয়ে এগুলোর সবকটা ধাপে ধাপে দেখতে [Feature যোগ করা](/development/adding-a-feature/)
দেখুন।
