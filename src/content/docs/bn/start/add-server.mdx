একটা panel অনেক server চালাতে পারে। একটা server যোগ করতে আপনি panel-এ তার একটা নাম দেন, আর panel
যে একটা command দেখায় সেটা নতুন server-এ চালান। Command-টা ekPanel agent আর web server install করে,
server-টাকে panel-এর সাথে connect করে, তারপর server-টা live পরিসংখ্যান-সহ দেখা যায়। এরপর তাতে
website, database আর app host করতে পারবেন।

<Aside type="note" title="প্রথম release-এর আগে">
এই একটা command GitHub থেকে panel-এর নিজের release download করে। প্রথম release publish না হওয়া
পর্যন্ত আপনার panel source থেকে build করা, তাই
[Panel যখন publish করা release নয়](#when-the-panel-is-not-a-published-release)-এর ধাপগুলো ব্যবহার
করুন।
</Aside>

## Enrolment কীভাবে কাজ করে

1. Panel-এ আপনি একটা নাম দিয়ে server যোগ করেন। Panel উত্তরে দেয় একটা **একবারের token**
   (one-time token) আর **CA pin**, অর্থাৎ panel-এর private certificate authority-র fingerprint।
2. নতুন server-এ `ekpanel-agent enroll` (installer আপনার হয়ে এটা চালায়) TCP port 7443-এ panel-এর
   সাথে connect করে। এটা panel-এর certificate-কে CA pin-এর সাথে মিলিয়ে দেখে, তাই কেউ ধোঁকা দিয়ে
   একে অন্য machine-এর সাথে কথা বলাতে পারে না।
3. Agent একটা private key বানায়, যা কখনো server ছেড়ে যায় না, আর একটা certificate request-এর
   সাথে token পাঠায়। Panel token check করে 90 দিনের জন্য বৈধ একটা client certificate sign করে
   দেয়। এরপর token-টা আর কাজে লাগে না।
4. Agent তার credential রাখে `/etc/ekpanel/agent.json`-এ (শুধু root পড়তে পারে)।
5. `ekpanel-agent run` **mutual TLS** দিয়ে panel-এর সাথে একটা WebSocket connection খোলা রাখে:
   দুই পক্ষই certificate দিয়ে প্রমাণ করে তারা কে। মেয়াদ শেষের 30 দিন আগে agent নিজেই তার
   certificate renew করে, আর যেকোনো বিচ্ছিন্নতার পরে আবার connect করে।

Connection সবসময় খোলে **agent**। এর জন্য নতুন server-এ কোনো incoming port খোলা লাগে না, তাই
এটা NAT বা বাসার router-এর পেছনেও থাকতে পারে। শুধু panel-এর server-কে port 7443-এ connection
নিতে হয়।

Token কাজ করে **একবারই**, আর **এক ঘণ্টা পরে মেয়াদ শেষ** হয়ে যায়। Panel এর শুধু একটা hash রাখে।

## শুরু করার আগে

Panel-এর server-এ:

- নতুন server থেকে TCP port **7443**-এ পৌঁছানো যেতে হবে। ufw চালু থাকলে installer ufw-এ এটা খোলে;
  আপনার provider-এর cloud firewall-এও এটা খুলুন।

নতুন server-এ:

- amd64 বা arm64-এ Ubuntu 24.04+ বা Debian 12+, systemd-সহ, ঠিক
  [panel-এর server](/start/requirements/)-এর মতো। নতুন একটা server নিন: ekPanel-এর web server-এর
  port 80 আর 443 লাগে। Feature-গুলোর যা লাগে, যেমন PHP, MariaDB বা Docker, agent সেগুলো `apt`
  দিয়ে install করে।
- Root access। Agent root হিসেবে চলে, কারণ এটাই server চালায়।
- Port 7443-এ panel-এর দিকে, release-এর জন্য HTTPS-এ `github.com`-এর দিকে, আর package-এর জন্য
  internet-এর দিকে outgoing access।

## Server যোগ করুন

<Steps>

1. Panel-এ **সার্ভার** (Servers) খুলে **সার্ভার যোগ করুন** (Add server)-এ click করুন।

2. চিনতে পারবেন এমন একটা **সার্ভারের নাম** (Server name) দিন, যেমন "Singapore web 1", আর
   **এগিয়ে যান** (Continue)-এ click করুন।

3. **… যুক্ত করুন** (Connect …) dialog-এ **বসান আর যুক্ত করুন** (Install and connect)-এর নিচে একটা
   command দেখায়। দেখতে এ রকম:

   ```bash
   curl -fsSL https://github.com/ekPanel/ekpanel/releases/download/v0.1.0/install.sh | sudo bash -s -- --agent \
     --panel panel.example.com:7443 \
     --token <one-time token> \
     --ca-pin sha256:<fingerprint>
   ```

   Address-এর version-টা আপনার panel-এর নিজের version, তাই নতুন server panel-এর মতো একই version-এর
   agent পায়। Browser-এ আপনি যে host নামে panel খুলেছেন, panel সেটা আর agent port নিজেই বসিয়ে
   দেয়।

4. Copy button দিয়ে command-টা copy করে নতুন server-এ root হিসেবে চালান। কয়েক মিনিট লাগে, বেশিরভাগই
   package download, আর শেষে দেখায় "This server is connected to the panel."

5. Panel-এ ফিরে দেখবেন, কয়েক সেকেন্ডের মধ্যে dialog **এজেন্ট যুক্ত হওয়ার অপেক্ষা করছি…** (Waiting
   for the agent to connect…) থেকে বদলে **যুক্ত হয়েছে!** (Connected!) হয়ে যায়। **সম্পন্ন**
   (Done)-এ click করুন।

</Steps>

Server-টা এখন **সার্ভার** page-এ **অনলাইন** (Online) দেখায়, আর website, database বা app যোগ
করার সময় এটা বেছে নিতে পারবেন।

### Command-টা কী করে

এটা panel-এর মতো একই installer চালায়, `--agent`-সহ। নতুন server-এ এটা:

- `ca-certificates`, `curl`, `gnupg`, `openssl`, `acl` আর Ubuntu-তে `software-properties-common`
  install করে, আর Caddy আগে থেকে না থাকলে Caddy-র official package repository থেকে সেটাও।
  PostgreSQL বা panel install করে না;
- Panel-এর release থেকে agent download করে check করে, ঠিক যেমন
  [panel-এর install](/start/install/#how-the-download-is-checked) করে;
- এটাকে `/usr/local/bin/ekpanel-agent` হিসেবে বসায়, `/etc/ekpanel` আর `/etc/ekpanel/caddy/sites`
  তৈরি করে (web server পড়তে পারে এমনভাবে), আর `ekpanel-agent` systemd service লেখে;
- Token আর CA pin দিয়ে agent enrol করে, তারপর service চালু আর enable করে, যাতে reboot-এর পরেও
  agent চলে;
- `/etc/caddy/Caddyfile` লেখে, যা `/etc/ekpanel/caddy/sites/*.caddy` import করে (প্রতিটা
  website-এর জন্য একটা file, agent লেখে)। Server-এ আগে থেকে নিজস্ব Caddyfile থাকলে installer শুধু
  তাতে `import` line-টা যোগ করে। তারপর configuration check করে Caddy reload করে;
- ufw চালু থাকলে তাতে port 80 আর 443 খোলে।

আগে থেকে connect থাকা server-এ একই command আবার চালালে agent আবার install হয়, connection থেকে যায়;
দ্বিতীয়বার enrol হয় না। Panel-এর নিজের server-এ `--agent` দিয়ে installer চলতে রাজি হয় না, কারণ
সেখানকার agent panel-এর installer আগেই set up করেছে।

## Panel যখন publish করা release নয়

একটা command-এর জন্য দরকার আপনার panel-এর version GitHub-এ release হিসেবে থাকা। আপনি
[নিজে panel build করলে](/start/install/#install-from-your-own-build) সেটা থাকে না:

- **Source থেকে** build করা panel (`make build` দিয়ে, বা release নয় এমন version) এর বদলে দুটো command
  দেখায়, সাথে এই note: "এই প্যানেল সোর্স থেকে বানানো, তাই বসানোর মতো কোনো রিলিজ নেই। আগে
  ekpanel-agent ফাইলটা নতুন সার্ভারের /usr/local/bin-এ কপি করুন।"
- `make release VERSION=…` দিয়ে build করা panel একটা command-ই দেখায়, কিন্তু তার download GitHub-এ
  নেই, তাই 404 error দিয়ে fail করে।

দুই ক্ষেত্রেই dialog-এর value দিয়ে নিজের build থেকে installer চালান:

<Steps>

1. যে archive থেকে panel install করেছিলেন (একই version) সেটা নতুন server-এ copy করে সেখানে unpack
   করুন:

   ```bash
   scp dist/ekpanel-v0.0.1-linux-amd64.tar.gz root@new-server:
   ```

   ```bash
   tar -xzf ekpanel-v0.0.1-linux-amd64.tar.gz
   cd ekpanel-v0.0.1-linux-amd64
   ```

   `make build`-এর build হলে এর বদলে `bin/ekpanel-agent` আর `deploy/install.sh` নতুন server-এ এক
   folder-এ copy করুন।

2. Panel-এ **সার্ভার যোগ করুন** (Add server)-এ click করে নাম দিন, **এগিয়ে যান** (Continue)-এ click
   করুন। Dialog যে command দেখায়, তা থেকে `--panel`, `--token` আর `--ca-pin`-এর value নিন।

3. `--agent` আর ওই value-গুলো দিয়ে installer চালান:

   ```bash
   sudo ./install.sh --agent --local-dir . \
     --panel panel.example.com:7443 \
     --token <one-time token> \
     --ca-pin sha256:<fingerprint>
   ```

   [Command-টা কী করে](#what-the-command-does)-এ লেখা সবই এটা করে, শুধু download ছাড়া।

4. Dialog-এ **যুক্ত হয়েছে!** (Connected!) আসা পর্যন্ত অপেক্ষা করে **সম্পন্ন** (Done)-এ click করুন।

</Steps>

Source থেকে build করা panel-এর দুটো command (`sudo ekpanel-agent enroll …`, তারপর
`sudo ekpanel-agent run`)-ও কাজ করে, যদি `ekpanel-agent` আগে `/usr/local/bin`-এ থাকে। এরা শুধু
agent connect করে: কোনো web server, `acl` package বা systemd service set up করে না, আর `run`
agent-কে আপনার SSH session-এর foreground-এ রাখে। দ্রুত একটা test-এর জন্য এগুলো ব্যবহার করুন, website
host করবে এমন server-এর জন্য নয়।

### `enroll` command

```text
ekpanel-agent enroll --panel HOST[:7443] --token TOKEN --ca-pin sha256:... [--config PATH]
```

| Flag | মানে |
| --- | --- |
| `--panel` | Agent-দের জন্য panel-এর address। Port না দিলে 7443 ব্যবহার হয়। |
| `--token` | Panel থেকে পাওয়া একবারের enrolment token। |
| `--ca-pin` | Panel-এর agent CA-র fingerprint, token-এর সাথে দেখানো হয়। |
| `--config` | Credential কোথায় save হবে। Default `/etc/ekpanel/agent.json`। |

`ekpanel-agent run [--config PATH]` agent চালু করে, আর `ekpanel-agent version` তার version দেখায়।

## Panel-এর নিজের server কীভাবে connect হয়

Panel-এর নিজের server আপনাকে হাতে যোগ করতে হয় না। Installer panel-এর server-এ
`ekpanel add-server` চালায়, যা server-টাকে তার host নামে register করে আর একটা token ও CA pin দেখায়, তারপর
local agent-কে `127.0.0.1:7443`-এ enrol করে। ওপরের মতো একই enrolment, শুধু automatic।

## NAT বা firewall-এর পেছনে

- **নতুন server** NAT, বাসার router বা কড়া firewall-এর পেছনে থাকতে পারে। এর শুধু TCP port
  7443-এ panel পর্যন্ত পৌঁছাতে পারলেই হয়। অবশ্য এর website-গুলোর জন্য internet থেকে port 80 আর
  443-এ পৌঁছানো যেতে হবে।
- **Panel-এর server**-কে আপনার server-গুলো থেকে TCP 7443 নিতে হবে। Panel নিজেই NAT-এর পেছনে থাকলে
  port 7443 তার দিকে forward করুন।
- DNS record আর FTP-এর জন্য ekPanel server-এর জানানো প্রথম public address ব্যবহার করে। NAT-এর
  পেছনের server শুধু তার private address জানে, তাই server-এর page-এ হাতে তার public address
  বসিয়ে দিন। দেখুন [server guide](/guides/admin/servers/)।

<Aside type="caution" title="Cloudflare-এর proxy-র পেছনে panel-এর domain">
Agent-রা panel-এর নিজস্ব certificate authority দিয়ে mutual TLS ব্যবহার করে, মাঝখানে একটা proxy
থাকলে সেটা ভেঙে যায়। আপনার panel-এর domain যদি Cloudflare-এর মধ্য দিয়ে proxied হয় (কমলা
মেঘ), তাহলে `--panel`-এ server-এর IP address বা proxied নয় এমন একটা নাম ব্যবহার করুন।
</Aside>

## কিছু ভুল হলে

- **Token-এর মেয়াদ শেষ, বা command হারিয়ে গেছে।** **সার্ভার** page-এ server-টা খুলে **নতুন সংযোগ
  কমান্ড** (New connection command)-এ click করুন। এটা নতুন token বানায় আর server-এর বর্তমান
  certificate বাতিল করে, তাই আগে থেকে connect থাকা agent বিচ্ছিন্ন হয়ে যায়, যতক্ষণ না আপনি আবার
  enrol করেন। যে server-এ agent আগে থেকেই install করা, সেখানে এক লাইনের command আবার enrol করে না
  (আগের credential রেখে দেয়), তাই নতুন command-এর value দিয়ে `enroll` অংশটা নিজে চালান, তারপর agent
  restart করুন:

  ```bash
  sudo ekpanel-agent enroll --panel panel.example.com:7443 --token <one-time token> --ca-pin sha256:<fingerprint>
  sudo systemctl restart ekpanel-agent
  ```
- **"the panel did not accept this server. The token works once and expires; create a new one
  in the panel."** (installer থেকে), বা **"panel refused the request"** (`enroll` থেকে): token
  আগেই ব্যবহার হয়ে গেছে বা মেয়াদ শেষ। নতুন connection command বানান।
- **"contact panel" error বা timeout**: server port 7443-এ panel পর্যন্ত পৌঁছাতে পারছে না।
  Panel-এর firewall আর আপনার provider-এর cloud firewall check করুন।
- **`curl: (22) The requested URL returned error: 404`**: আপনার panel-এর version কোনো publish করা
  release নয়। দেখুন
  [Panel যখন publish করা release নয়](#when-the-panel-is-not-a-published-release)।
- **"this server runs the panel; its agent is already set up."**: আপনি panel-এর নিজের server-এ
  `--agent` command চালিয়েছেন। সেখানে আর কিছু লাগে না।
- **Server অফলাইন (Offline) দেখায়**: agent চলছে না বা connect করতে পারছে না। Server-এ
  `sudo systemctl status ekpanel-agent` আর `sudo journalctl -u ekpanel-agent` দেখুন।
- **একটা server সরাতে** সেটা খুলে delete করুন। Panel server-টাকে ভুলে যায় আর তার agent আর
  connect করতে পারে না। Server-এর ভেতরের কিছুই delete হয় না; সেখানে agent service নিজেই stop
  আর disable করুন (`sudo systemctl disable --now ekpanel-agent`)।
