একটা panel অনেক server চালাতে পারে। একটা server যোগ করতে আপনি তাতে ekPanel agent বসান আর panel
থেকে পাওয়া একটা command চালান, তারপর server-টা live পরিসংখ্যান-সহ দেখা যায়। এরপর তাতে website,
database আর app host করতে পারবেন।

<Aside type="note" title="ভবিষ্যতের চেয়ে বেশি হাতের কাজ">
শুধু agent-এর জন্য কোনো installer এখনো নেই; এটা আসবে প্রথম release-এর সাথে
([roadmap](/project/roadmap/), phase 4a)। আজকের দিনে agent program-টা আপনাকে নিজেই copy করতে
হয়, আর server-টা website host করলে তাতে Caddy তৈরি করে নিতে হয়। এই page-এ প্রতিটা ধাপ দেখানো আছে।
</Aside>

## Enrolment কীভাবে কাজ করে

1. Panel-এ আপনি একটা নাম দিয়ে server যোগ করেন। Panel উত্তরে দেয় একটা **একবারের token**
   (one-time token) আর **CA pin**, অর্থাৎ panel-এর private certificate authority-র fingerprint।
2. নতুন server-এ `ekpanel-agent enroll` TCP port 7443-এ panel-এর সাথে connect করে। এটা panel-এর
   certificate-কে CA pin-এর সাথে মিলিয়ে দেখে, তাই কেউ ধোঁকা দিয়ে একে অন্য machine-এর সাথে কথা
   বলাতে পারে না।
3. Agent একটা private key বানায়, যা কখনো server ছেড়ে যায় না, আর একটা certificate request-এর
   সাথে token পাঠায়। Panel token check করে 90 দিনের জন্য বৈধ একটা client certificate sign করে
   দেয়। এরপর token-টা আর কাজে লাগে না।
4. Agent তার credential রাখে `/etc/ekpanel/agent.json`-এ (শুধু root পড়তে পারে)।
5. `ekpanel-agent run` **mutual TLS** দিয়ে panel-এর সাথে একটা WebSocket connection খোলা রাখে:
   দুই পক্ষই certificate দিয়ে প্রমাণ করে তারা কে। মেয়াদ শেষের 30 দিন আগে agent নিজেই তার
   certificate renew করে, আর যেকোনো বিচ্ছিন্নতার পরে আবার connect করে।

Connection সবসময় খোলে **agent**। এর জন্য নতুন server-এ কোনো incoming port খোলা লাগে না, তাই
এটা NAT বা বাসার router-এর পেছনেও থাকতে পারে। শুধু panel-এর server-কে port 7443-এ connection
নিতে হয়।

Token কাজ করে **একবারই**, আর **এক ঘণ্টা পরে মেয়াদ শেষ** হয়ে যায়। Panel এর শুধু একটা hash রাখে।

## শুরু করার আগে

Panel-এর server-এ:

- নতুন server থেকে TCP port **7443**-এ পৌঁছানো যেতে হবে। ufw চালু থাকলে installer ufw-এ এটা খোলে;
  আপনার provider-এর cloud firewall-এও এটা খুলুন।

নতুন server-এ:

- amd64 বা arm64-এ Ubuntu 24.04+ বা Debian 12+, systemd-সহ, ঠিক
  [panel-এর server](/start/requirements/)-এর মতো। Feature-গুলোর যা লাগে, যেমন PHP, MariaDB বা
  Docker, agent সেগুলো `apt` দিয়ে install করে।
- Root access। Agent root হিসেবে চলে, কারণ এটাই server চালায়।
- Port 7443-এ panel-এর দিকে, আর package-এর জন্য internet-এর দিকে outgoing access।
- এর CPU type-এর জন্য build করা `ekpanel-agent` program। এটা panel-এর মতোই একই
  [release archive](/start/install/#build-ekpanel)-এ আছে (`make release`)।

## Server তৈরি করুন

<Steps>

1. Agent-টা server-এ copy করে install করুন:

   ```bash
   scp ekpanel-agent root@new-server:
   ```

   তারপর নতুন server-এ:

   ```bash
   sudo install -m 0755 ekpanel-agent /usr/local/bin/ekpanel-agent
   sudo install -d -m 0755 /etc/ekpanel
   ```

   দ্বিতীয় command-টা agent-এর folder এমনভাবে তৈরি করে যাতে web server সেটা পড়তে পারে, যেমনটা
   panel-এর installer করে। Agent নিজে এটা তৈরি করলে root ছাড়া সবার জন্য বন্ধ থাকত, আর agent
   সেখানে যে website file লেখে Caddy সেগুলো পড়তে পারত না।

2. এই server যদি **domain-সহ website বা app** host করে, তাহলে Caddy আর `acl` package install
   করুন, আর Caddy-কে সেই folder দেখিয়ে দিন যেখানে agent প্রতিটা website-এর জন্য একটা করে file
   লেখে। Panel-এর installer panel-এর server-এ এটা করে দেয়; অন্য server-এ আপাতত আপনি একবার
   হাতে করবেন:

   ```bash
   sudo apt-get update
   sudo apt-get install -y curl gnupg acl
   curl -fsSL https://dl.cloudsmith.io/public/caddy/stable/gpg.key | sudo gpg --dearmor --yes -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
   curl -fsSL https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt | sudo tee /etc/apt/sources.list.d/caddy-stable.list
   sudo apt-get update
   sudo apt-get install -y caddy
   sudo install -d -m 0755 /etc/ekpanel/caddy/sites
   ```

   তারপর `/etc/caddy/Caddyfile`-এর জায়গায় এটা দিন:

   ```text
   # Websites are in /etc/ekpanel/caddy/sites.
   import /etc/ekpanel/caddy/sites/*.caddy
   ```

   আর `sudo systemctl reload caddy` দিয়ে Caddy reload করুন। Ubuntu-তে
   `software-properties-common`-ও install করুন, PHP package repository যোগ করতে agent এটা ব্যবহার
   করে।

3. Agent-এর systemd service তৈরি করুন, যাতে boot-এর সময় এটা চালু হয় আর থেমে গেলে আবার চালু হয়।
   Panel-এর server-এ installer ঠিক এই unit-ই লেখে। এটা
   `/etc/systemd/system/ekpanel-agent.service` নামে save করুন:

   ```ini
   [Unit]
   Description=ekPanel agent
   After=network-online.target
   Wants=network-online.target

   [Service]
   # The agent manages this server (websites, services, files), so it runs as root.
   ExecStart=/usr/local/bin/ekpanel-agent run --config /etc/ekpanel/agent.json
   Restart=always
   RestartSec=3

   [Install]
   WantedBy=multi-user.target
   ```

   তারপর `sudo systemctl daemon-reload` চালান। এখনই এটা চালু করবেন না।

</Steps>

<Aside type="caution" title="Recipe হিসেবে পরীক্ষা করা হয়নি">
ধাপ 2 panel-এর installer যা set up করে সেটাই নকল করে, আর agent ঠিক সেটাই আশা করে (Caddy-র
configuration `/etc/caddy/Caddyfile`-এ, website file `/etc/ekpanel/caddy/sites`-এ, আর `acl`
package থেকে `setfacl`)। আলাদা recipe হিসেবে এটা এখনো পরীক্ষা করা হয়নি। নতুন server-এর কোনো
website যদি **সমস্যা** (Problem) দেখায়, website-এর page-এর message বলে দেয় কী নেই।
</Aside>

## Panel-এর সাথে connect করুন

<Steps>

1. Panel-এ **সার্ভার** (Servers) খুলে **সার্ভার যোগ করুন** (Add server)-এ click করুন।

2. চিনতে পারবেন এমন একটা **সার্ভারের নাম** (Server name) দিন, যেমন "Singapore web 1", আর
   **এগিয়ে যান** (Continue)-এ click করুন।

3. **… যুক্ত করুন** (Connect) dialog-এ server-এ চালানোর command দেখায়। দেখতে এ রকম:

   ```bash
   sudo ekpanel-agent enroll \
     --panel panel.example.com:7443 \
     --token <one-time token> \
     --ca-pin sha256:<fingerprint>
   ```

   Browser-এ আপনি যে host নামে panel খুলেছেন, panel সেটা আর agent port নিজেই বসিয়ে দেয়। Copy
   button দিয়ে command-টা copy করে নতুন server-এ চালান। এটা উত্তর দেয় `Enrolled as server …`।

4. Agent চালু করুন। Dialog-এ `sudo ekpanel-agent run` দেখায়, যা এটাকে foreground-এ চালায়। তার
   বদলে ওপরের ধাপের service ব্যবহার করুন, যাতে reboot-এর পরেও এটা চলে:

   ```bash
   sudo systemctl enable --now ekpanel-agent
   ```

5. Panel-এ ফিরে দেখবেন, কয়েক সেকেন্ডের মধ্যে dialog **এজেন্ট যুক্ত হওয়ার অপেক্ষা করছি…** (Waiting
   for the agent to connect…) থেকে বদলে **যুক্ত হয়েছে!** (Connected!) হয়ে যায়। **সম্পন্ন**
   (Done)-এ click করুন।

</Steps>

Server-টা এখন **সার্ভার** page-এ **অনলাইন** (Online) দেখায়, আর website, database বা app যোগ
করার সময় এটা বেছে নিতে পারবেন।

### `enroll` command

```text
ekpanel-agent enroll --panel HOST[:7443] --token TOKEN --ca-pin sha256:... [--config PATH]
```

| Flag | মানে |
| --- | --- |
| `--panel` | Agent-দের জন্য panel-এর address। Port না দিলে 7443 ব্যবহার হয়। |
| `--token` | Panel থেকে পাওয়া একবারের enrolment token। |
| `--ca-pin` | Panel-এর agent CA-র fingerprint, token-এর সাথে দেখানো হয়। |
| `--config` | Credential কোথায় save হবে। Default `/etc/ekpanel/agent.json`। |

`ekpanel-agent run [--config PATH]` agent চালু করে, আর `ekpanel-agent version` তার version দেখায়।

## Panel-এর নিজের server কীভাবে connect হয়

Panel-এর নিজের server আপনাকে হাতে যোগ করতে হয় না। Installer panel-এর server-এ
`ekpanel add-server` চালায়, যা server-টাকে তার host নামে register করে আর একটা token ও CA pin দেখায়, তারপর
local agent-কে `127.0.0.1:7443`-এ enrol করে। ওপরের মতো একই enrolment, শুধু automatic।

## NAT বা firewall-এর পেছনে

- **নতুন server** NAT, বাসার router বা কড়া firewall-এর পেছনে থাকতে পারে। এর শুধু TCP port
  7443-এ panel পর্যন্ত পৌঁছাতে পারলেই হয়। অবশ্য এর website-গুলোর জন্য internet থেকে port 80 আর
  443-এ পৌঁছানো যেতে হবে।
- **Panel-এর server**-কে আপনার server-গুলো থেকে TCP 7443 নিতে হবে। Panel নিজেই NAT-এর পেছনে থাকলে
  port 7443 তার দিকে forward করুন।
- DNS record আর FTP-এর জন্য ekPanel server-এর জানানো প্রথম public address ব্যবহার করে। NAT-এর
  পেছনের server শুধু তার private address জানে, তাই server-এর page-এ হাতে তার public address
  বসিয়ে দিন। দেখুন [server guide](/guides/admin/servers/)।

<Aside type="caution" title="Cloudflare-এর proxy-র পেছনে panel-এর domain">
Agent-রা panel-এর নিজস্ব certificate authority দিয়ে mutual TLS ব্যবহার করে, মাঝখানে একটা proxy
থাকলে সেটা ভেঙে যায়। আপনার panel-এর domain যদি Cloudflare-এর মধ্য দিয়ে proxied হয় (কমলা
মেঘ), তাহলে `--panel`-এ server-এর IP address বা proxied নয় এমন একটা নাম ব্যবহার করুন।
</Aside>

## কিছু ভুল হলে

- **Token-এর মেয়াদ শেষ, বা command হারিয়ে গেছে।** **সার্ভার** page-এ server-টা খুলে **নতুন সংযোগ
  কমান্ড** (New connection command)-এ click করুন। এটা নতুন token বানায় আর server-এর বর্তমান
  certificate বাতিল করে, তাই আগে থেকে connect থাকা agent বিচ্ছিন্ন হয়ে যায়, যতক্ষণ না আপনি আবার
  enrol করেন।
- **"panel refused the request"**: token আগেই ব্যবহার হয়ে গেছে বা মেয়াদ শেষ। নতুন connection
  command বানান।
- **"contact panel" error বা timeout**: server port 7443-এ panel পর্যন্ত পৌঁছাতে পারছে না।
  Panel-এর firewall আর আপনার provider-এর cloud firewall check করুন।
- **Server অফলাইন (Offline) দেখায়**: agent চলছে না বা connect করতে পারছে না। Server-এ
  `sudo systemctl status ekpanel-agent` আর `sudo journalctl -u ekpanel-agent` দেখুন।
- **একটা server সরাতে** সেটা খুলে delete করুন। Panel server-টাকে ভুলে যায় আর তার agent আর
  connect করতে পারে না। Server-এর ভেতরের কিছুই delete হয় না; সেখানে agent service নিজেই stop
  আর disable করুন।
