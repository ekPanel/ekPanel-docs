ekPanel একটা control panel, যা আপনি নিজের Linux server-এ install করেন। একটা web page থেকেই
আপনি এক বা একাধিক server-এ website, database, Docker app, email আর DNS host করতে পারেন, আর
customer-দের তাদের নিজস্ব account দিতে পারেন।

**ek** (এক) মানে বাংলায় "এক": আপনার পুরো hosting-এর জন্য একটাই panel।

<Aside type="caution" title="এখনো শুরুর দিকের development">
একটা test server-এ ekPanel শুরু থেকে শেষ পর্যন্ত কাজ করে, কিন্তু এর এখনো কোনো release নেই। আজকের
দিনে আপনাকে source থেকে build করে একটা script দিয়ে install করতে হয়। এখনই এতে গুরুত্বপূর্ণ কিছু
host করবেন না। প্রথম release-এর আগে কী কী আসছে, তা [roadmap](/project/roadmap/)-এ দেখুন।
</Aside>

## এটা কাদের জন্য

- **যাঁরা প্রথম VPS নিয়েছেন**, আর আগে server-এর সব tool না শিখেই একটা website বা WordPress
  blog online করতে চান।
- **Developer-রা**, যাঁরা নিজের নিয়ন্ত্রণে থাকা server-এ, PHP site-এর পাশাপাশি Git থেকে Docker
  দিয়ে app deploy করতে চান।
- **Hosting company আর agency**, যারা অন্যদের site host করে, আর যাদের customer account,
  limit-সহ package, backup আর একাধিক server দরকার।
- **Contributor-রা**, যাঁরা শেখার আর উন্নত করার জন্য একটা খোলা, পড়তে সহজ code base চান।

প্রতিটা screen English আর বাংলায় আছে, আর panel-টা এমনভাবে বানানো যাতে আরও ভাষা যোগ করা যায়।

এর ওপরে আছে firewall, CrowdSec, malware scan, দেশ ধরে block করা, two-factor sign-in, এমন

পাবেন [feature list](/start/features/)-এ।

## Panel আর agent

ekPanel-এর দুটো অংশ। **Panel** মনে রাখে কী কী থাকার কথা (website, database, app, setting) আর
আপনাকে web interface দেখায়; প্রতিটা server-এ থাকা একটা ছোট **agent** panel-এর সাথে connect
করে আর সেই server-এ আসল কাজটা করে।

Panel আপনি একবারই install করেন। প্রতিটা server-এ, panel-এর নিজের server-সহ, একটা করে agent
চলে। বিস্তারিত জানতে চাইলে [architecture](/concepts/architecture/) পড়ুন।

## অন্যদের সাথে তুলনা

ওপরের panel-গুলো থেকে ekPanel আইডিয়া নিয়েছে, কিন্তু এটা একটা আলাদা project, আর এখনো নতুন।
কিছু কথা জেনে রাখুন:

| | আজকের ekPanel |
| --- | --- |
| Licence | [AGPL-3.0](/project/license/)-এর অধীনে free software। কোনো paid edition নেই। |
| Server | একটা panel অনেক server চালায়। প্রতিটা server-এ একটা agent চলে, যা নিজে থেকে panel-এ connect করে, তাই NAT-এর পেছনে থাকা server-ও কাজ করে। |
| পরিবর্তন কীভাবে server-এ পৌঁছায় | Panel প্রতিটা server-এর পুরো কাঙ্ক্ষিত অবস্থা (wanted state) রাখে, আর agent server-টাকে সেই অবস্থায় নিয়ে আসে, প্রতি 10 মিনিটেও একবার। দেখুন [desired state](/concepts/desired-state/)। |
| Operating system | Ubuntu 24.04 বা তার নতুন, আর Debian 12 বা 13। Red Hat পরিবারের system এখনো না। |
| Release | এখনো নেই। এক লাইনের installer নেই, নিজে নিজে update-ও নেই। |
| এখনো নেই | Reseller, অন্য panel থেকে importer, এক server থেকে আরেক server-এ site সরানো, WAF, token-সহ API, billing। দেখুন [features](/start/features/#not-yet)। |

আজই যদি paying customer-দের জন্য একটা পরিণত, support-সহ panel দরকার হয়, ekPanel সেটার জন্য
এখনো তৈরি না। আর যদি চালিয়ে দেখতে চান, feedback দিতে চান বা বানাতে সাহায্য করতে চান, তাহলে
আপনি ঠিক জায়গায় এসেছেন।
