## Website

[Website guide](/guides/websites/websites/) · [PHP](/guides/websites/php/) · [Redirect](/guides/websites/redirects/)

- Static site আর PHP site। PHP 7.4, 8.1, 8.2, 8.3, 8.4 আর 8.5 পাশাপাশি চলে; কোনো site-এর
  প্রথমবার যে version দরকার হয়, সেটা তখনই install হয়।
- কোনো downtime ছাড়াই একটা site-এর PHP version বদলানো।
- Let's Encrypt থেকে free, automatic HTTPS, testing-এর জন্য self-signed certificate, অথবা আপনার
  নিজের certificate (এর key আর domain-এর সাথে মিলিয়ে দেখা হয়, আর মেয়াদ শেষ হওয়ার দুই সপ্তাহ আগে
  একটা notice আসে)।
- প্রতিটা site-এ বাড়তি domain, default হিসেবে `www.` দেওয়া থাকে, আর যেকোনো লিপিতে domain নাম।
- প্রতিটা site নিজের Linux account আর নিজের PHP-FPM pool দিয়ে চলে, তাই এক site আরেক site-এর
  file পড়তে পারে না।
- নির্দিষ্ট path বা prefix-এর redirect (301, 302, 307, 308), আর এমন বাড়তি domain যা মূল domain-এ
  redirect করে।
- বাছাই করা file type-এর জন্য hotlink protection, সাথে যেসব site তবুও সেগুলো embed করতে পারবে।
- প্রতিটা site-এর জন্য PHP setting (memory limit, upload size, execution time, time zone আর আরও
  কিছু), আর প্রতিটা server-এ 17টা ঐচ্ছিক PHP extension (redis, imagick, apcu, xdebug আর অন্যান্য)।
- যেসব app একটা `public/` বা `web/` folder serve করে, তাদের জন্য document root setting।
- `.env` আর `.git`-এর মতো file কখনো serve করা হয় না।

## WordPress

[WordPress guide](/guides/websites/wordpress/)

- এক click-এ WordPress, নিজস্ব MariaDB database-সহ, 14টা ভাষায়। Admin password একবারই দেখানো
  হয়, কোথাও রাখা হয় না।
- সব WordPress site এক তালিকায়, হাতে install করাগুলোও।
- Core, plugin আর theme update, আর update-এর পরে site error দেখালে সেটা নিজে থেকেই আগের অবস্থায়
  ফিরে যায়; প্রতিটা site-এর জন্য নিয়ম ধরে automatic update।
- Maintenance mode, plugin চালু-বন্ধ, আর debug mode চালু থাকলে একটা সতর্কবার্তা।
- Hardening: dashboard থেকে code edit করা বন্ধ, `xmlrpc.php` আর uploads-এর ভেতরে PHP block, file
  permission ঠিক করা।
- `staging.<domain>`-এ একটা staging copy, যেটা আপনি live site-এ push করতে পারেন বা live site থেকে
  refresh করতে পারেন।

## File, SFTP আর FTP

[File guide](/guides/websites/files/)

- Browser-এ একটা file manager: upload (drag and drop), download, একটা code editor, নতুন file আর
  folder, rename, permission, zip আর unzip, আর একটা trash, যেখান থেকে ফিরিয়ে আনা যায়।
- প্রতিটা site-এর জন্য SFTP, password বা SSH key দিয়ে, site-এর folder-এর মধ্যে আটকানো আর shell
  ছাড়া।
- যেসব tool-এর FTP লাগে তাদের জন্য FTP: শুধু encrypted (FTPS), প্রতিটা site-এর জন্য একটা login,
  তার folder-এর মধ্যে আটকানো। কোনো site যতক্ষণ FTP ব্যবহার করে, firewall শুধু ততক্ষণ FTP port
  খোলা রাখে।

## Cron job

[Cron guide](/guides/websites/cron/)

- Website-এর জন্য job (site-এর account হিসেবে চলে) আর app-এর জন্য job (container-এর ভেতরে চলে)।
- Preset বা যেকোনো cron expression, আপনার time zone-এ, সাথে পরের পাঁচবার কখন চলবে তা দেখানো হয়।
- সময়সীমা, শেষ ফলাফল আর output, **এখনই চালান** (Run now) আর pause।
- <Badge text="পরের release" variant="note" /> Job fail করলে একটা alert
  ([Fail করলে alert](/guides/websites/cron/#failure-alerts)), আবার ঠিকমতো না চলা পর্যন্ত একবারই।

## Docker app

[Docker app guide](/guides/apps/docker-apps/)

- যেকোনো Docker image বা Compose file চালান, domain আর free HTTPS, variable, স্থায়ীভাবে রাখা
  folder, আর memory ও CPU limit-সহ।
- Container log, restart, stop আর start, আর এক click-এ **ইমেজ আপডেট** (Update image)।
- App-এর port `127.0.0.1`-এ থাকে, তাই Docker firewall-এ ফুটো করতে পারে না। যেসব Compose file
  public port খোলে, আপনি অনুমতি না দিলে সেগুলো নেওয়া হয় না।
- একটা app delete করলে তার data থেকে যায়, যদি না আপনি সেটাও delete করতে বেছে নেন।
- <Badge text="পরের release" variant="note" /> একটা app তার data সহ [অন্য server-এ সরান](/guides/apps/move/)।

  সরিয়ে ফেলা হয়। Fork থেকে আসা pull request-এর কখনো preview হয় না।

## Backup

[Backup guide](/guides/data/backups/)

- একটা server-এর প্রতিটা website আর database-এর encrypted, deduplicated backup (restic দিয়ে),
  server-এই অথবা S3-compatible storage-এ (Amazon S3, Backblaze B2, Cloudflare R2, Wasabi, MinIO
  আর অন্যান্য)।
- প্রতি ঘণ্টায়, প্রতিদিন, প্রতি সপ্তাহে বা হাতে, আর দৈনিক, সাপ্তাহিক ও মাসিক copy রেখে দেওয়া হয়।
- Encryption key হলো একটা recovery key, যা একবারই দেখানো হয়। Panel এটা কখনো রাখে না।
- একটা website নতুন folder-এ বা বর্তমান file-এর ওপরে restore করুন, আর database restore করুন
  তার জায়গাতেই।
- <Badge text="পরের release" variant="note" /> একটা server হারিয়ে গেলে, তার website-গুলো তাদের S3 backup থেকে
  [অন্য server-এ আবার বানান](/guides/websites/rebuild/)।

## DNSSEC-সহ আপনার নিজের name server

[Name server guide](/guides/dns/name-servers/)

- ekPanel server-গুলোকে name server (PowerDNS) বানান: একটা primary আর যতগুলো খুশি secondary,
  zone transfer দিয়ে sync-এ রাখা।
- A, AAAA, CNAME, MX, TXT, SRV, CAA আর NS record-এর জন্য একটা zone editor, আর নতুন zone-এর
  জন্য template।
- Website, app আর email-এর record নিজে থেকেই তৈরি হয়।
- প্রতিটা zone-এ DNSSEC, সাথে আপনার registrar-কে দেওয়ার DS record, আর glue record-এর জন্য
  নির্দেশনা।

## Email

[Email guide](/guides/dns/email/)

- Panel-এর set up করা একটা mail server (Stalwart), webmail-সহ (Roundcube)।
- Size-সহ mailbox, forwarder, catch-all, forwarding আর auto-reply।
- MX, SPF, DKIM আর DMARC record Cloudflare-এ বা আপনার নিজের name server-এ publish করা হয়, অথবা
  অন্য কোথাও copy করার জন্য দেখানো হয়।
- Reverse DNS, outgoing port 25 আর blocklist-এর জন্য একটা delivery check।

<Aside type="caution">
Email শুধু একটা test server-এর ভেতরেই পরীক্ষা করা হয়েছে। বাইরের আসল mail server-এ mail পাঠানো
আর সেখান থেকে mail পাওয়া এখনো চালিয়ে দেখা হয়নি।
</Aside>

## নিরাপত্তা

[নিরাপত্তার overview](/guides/security/overview/) · [Firewall](/guides/security/firewall/) · [CrowdSec](/guides/security/crowdsec/) · [Malware](/guides/security/malware/) · [দেশ](/guides/security/countries/) · [আপনার account](/guides/security/accounts/)

- প্রতিটা server-এর **overview**: firewall, CrowdSec, SSH-এ root আর password দিয়ে sign-in, বাকি
  থাকা update আর security update, restart দরকার কি না, আর two-factor sign-in ছাড়া
  administrator।
- **Firewall** (ufw): SSH, web আর agent port সবসময় খোলা থাকে; server page থেকে port খুলুন বা
  address block করুন। যেসব rule আপনাকে বাইরে আটকে ফেলবে, panel সেগুলো নেয় না।
- এক click-এ **CrowdSec**: SSH আর WordPress-এ password আন্দাজ করার চেষ্টা, scan আর exploit-এর
  চেষ্টা firewall-এ ban হয়, আর panel-এ ban, attack আর একটা allowlist দেখা যায়।
- ClamAV দিয়ে **malware scan**, প্রতিদিন, প্রতি সপ্তাহে বা যখন চান, quarantine-সহ। Website-এর
  মালিকরা নিজেদের site-এ কী পাওয়া গেছে তা দেখতে পান।
- **দেশ ধরে block**: কিছু দেশ block করুন, অথবা শুধু কিছু দেশকে অনুমতি দিন, DB-IP-এর free country
  list দিয়ে।
- **Account**: two-factor sign-in (TOTP), sign-in rate limiting, **অন্য সব ডিভাইস থেকে সাইন আউট**
  (Sign out all other devices), আর নতুন address থেকে sign-in হলে একটা alert।
- <Badge text="পরের release" variant="note" /> [Account-এর নিরাপত্তা](/guides/security/accounts/):
  two-factor sign-in-এর দশটা এক-বারের recovery code, একটা ব্যবহার হলে alert-সহ; customer তালিকা থেকে
  customer-এর two-factor sign-in reset, আর panel-এর server-এ `ekpanel reset-2fa` দিয়ে administrator-এর;
  password আর code-এর বদলে passkey (আঙুলের ছাপ, মুখ, PIN বা security key); আর sign in থাকা device-এর তালিকা,
  যার প্রতিটা আলাদা করে sign out করা যায়। Passkey একটা virtual authenticator দিয়ে test করা হয়েছে, আসল device
  দিয়ে এখনো নয়।
- প্রতিটা পরিবর্তনের একটা append-only audit log (শুধু যোগ করা যায়, মোছা বা বদলানো যায় না)।

## Customer আর package

[Customer guide](/guides/admin/customers/)

- Website, database, app, cron job, mail, disk space, memory আর CPU, PHP version, server, অনুমোদিত
  Docker image, Git app, SFTP আর FTP-এর limit-সহ package।
- Customer-রা একই panel-এ sign in করেন আর শুধু নিজেদের জিনিসই দেখেন।
- একজন customer-এর সব PHP আর container-এর memory ও CPU limit Linux kernel (cgroups) মানতে বাধ্য
  করে। Disk ব্যবহার প্রতি 30 মিনিটে মাপা হয়।
- **তাঁর হয়ে ঢুকুন** (Sign in as): এক ঘণ্টার জন্য একজন customer হিসেবে panel-এ ঢোকা, যা audit
  log-এ লেখা থাকে।
- <Badge text="পরের release" variant="note" /> একজন customer-এর এক server-এর
  [সবকিছু একবারে অন্য server-এ সরান](/guides/admin/move-customer/)।
- <Badge text="পরের release" variant="note" /> [একজন customer-কে suspend করুন](/guides/admin/customers/#suspend-a-customer):
  তিনি sign in করতে পারেন না, তাঁর website-এ একটা "suspended" page দেখায়, app আর cron job থামে, আর কিছুই মোছা হয় না।
- <Badge text="পরের release" variant="note" /> Website, database, app, email domain আর DNS zone-এর
  [মালিক বদলান](/guides/admin/customers/#change-the-owner), নতুন মালিকের package মিলিয়ে।
- <Badge text="পরের release" variant="note" /> Package-এ মাসিক [bandwidth limit](/guides/admin/customers/#how-bandwidth-is-counted),
  90% আর 100%-এ alert-সহ, আর package বললে পরের মাস পর্যন্ত website বন্ধ।
- <Badge text="পরের release" variant="note" /> [Reseller](/guides/admin/resellers/): তাঁরা নিজের customer-দের কাছে
  hosting বিক্রি করেন, নিজের package দিয়ে, আপনার ঠিক করা সীমার মধ্যে: সব customer মিলিয়ে মোট (customer-দের যা আছে তা
  গুনে), একটা package-এর সর্বোচ্চ, আর কোন server, PHP version ও image তাঁরা দিতে পারবেন। একজন reseller-কে suspend করলে
  তাঁর সব customer suspend হন; customer-এর মতোই reseller-এর bandwidth সীমিত আর বন্ধ করা যায়।

## অনেক server

[Server guide](/guides/admin/servers/) · [Server যোগ করা](/start/add-server/) · [আপডেট](/guides/admin/updates/) · [Website সরান](/guides/websites/move/) · [App সরান](/guides/apps/move/) · [Database সরান](/guides/data/move-database/) · [Customer সরান](/guides/admin/move-customer/) · [Backup থেকে আবার বানান](/guides/websites/rebuild/) · [cPanel থেকে ইমপোর্ট](/guides/admin/import-cpanel/) · [ওয়েবসাইট আর্কাইভ ইমপোর্ট](/guides/admin/import-website/) · [Coolify থেকে ইমপোর্ট](/guides/admin/import-coolify/)

- একটা command দিয়ে server যোগ করুন, যা agent আর web server install করে। Agent নিজে mutual TLS দিয়ে
  panel-এ connect করে, তাই NAT-এর পেছনেও কাজ করে।
- Sign করা release, আর এক লাইনের installer যা signature check করে। Panel নতুন release খুঁজে পায়, এক
  page থেকে নিজেকে আর তারপর প্রতিটা server-এর agent update করে, আগের version রেখে দেয়, আর নতুনটা চালু
  না হলে আগেরটা ফিরিয়ে আনে। (প্রথম release, v0.1.0, publish হয়েছে 9 November 2026-এ।)
- Live CPU, memory, disk, network, load আর uptime, 30 দিনের history-সহ।
- প্রতিটা server-এর service (Caddy, PostgreSQL, cron আর অন্যান্য), restart-সহ।
- Background task, panel-এ তাদের অগ্রগতি দেখা যায়।
- <Badge text="পরের release" variant="note" /> একটা website, আপনার বেছে নেওয়া database সহ, অন্য server-এ সরানো:
  file (owner আর ACL সহ), database আর certificate server-গুলোর agent-এর মধ্যে কপি হয়, কিছু বদলানোর আগে নতুন server
  যাচাই করা হয়, panel যে DNS চালায় তা পেছনে যায়, আর আপনি না মোছা পর্যন্ত পুরোনো কপি চলতে থাকে। দুটো VM দিয়ে test করা।
- <Badge text="পরের release" variant="note" /> একটা app অন্য server-এ সরানো: app বন্ধ করা হয়, তার Docker volume (সংখ্যায়
  owner সহ) আর Git app-এর বর্তমান build server-গুলোর agent-এর মধ্যে কপি হয়, নতুন server app set up করে তার volume ভরে,

## API আর command line

[REST API](/reference/api/) · [API token](/guides/security/api-tokens/) · [ekctl](/reference/cli/)

<Badge text="পরের release" variant="note" /> এগুলো main repository-র `dev` branch-এ আছে, আর আসবে v0.1.0-এর পরের
release-এ।

- Script-এর জন্য **API token**, administrator, reseller আর customer সবার জন্য: প্রতিটা অংশের scope (read, website,
  database, app, DNS, email, backup, server, customer, settings), মেয়াদ, একবার দেখানো, revoke করা যায়, শেষ ব্যবহার
  দেখা যায়, আর audit log-এ নাম থাকে। Token কখনো account-এর নিরাপত্তা বদলাতে বা terminal খুলতে পারে না।
- পুরো API-এর একটা **OpenAPI 3.1 description**, `/api/v1/openapi.json`-এ, প্রতিটা operation-এর দরকারি scope-সহ।
- **ekctl**, Linux, macOS আর Windows-এর জন্য একটা command-line tool: server, website, database, app, DNS, backup
  আর task, `--wait`, `--json` output, আর যেকোনো endpoint-এর জন্য `ekctl api`। Self-signed certificate-ওয়ালা
  panel fingerprint দিয়ে বিশ্বাস করা হয়।
