আজকের দিনে ekPanel install করতে আপনি দুটো program source থেকে build করেন, সেগুলো server-এ copy
করেন আর installer চালান। প্রায় দশ মিনিট লাগে, যার বেশিরভাগই download।

<Aside type="note" title="এক লাইনের installer এখনো নেই">
Signed release download করে এমন এক লাইনের installer আসবে প্রথম release-এর সাথে
([roadmap](/project/roadmap/), phase 4a)। ততদিন এই page-এর ধাপগুলো ব্যবহার করুন।
</Aside>

## শুরু করার আগে

- [যা যা লাগবে](/start/requirements/) তা পূরণ করে এমন একটা নতুন server, আর root বা `sudo`
  থাকা কোনো user হিসেবে তাতে SSH access।
- আপনার computer-এ: Linux, Go 1.27+, Node.js 22+, `make`, `git` আর `tar`।
- ঐচ্ছিক: panel-এর জন্য একটা domain নাম (যেমন `panel.example.com`), যার DNS record server-এর
  দিকে point করা। এখনই এটা তৈরি করুন, যাতে install-এর সময় Let's Encrypt এটা check করতে পারে।
- আপনার server-এর CPU type জেনে নিন। Server-এ `uname -m` চালান: `x86_64` মানে **amd64**,
  `aarch64` মানে **arm64**।

## ekPanel build করুন

ekPanel দুটো program: `ekpanel` (panel, web interface ভেতরেই build করা) আর `ekpanel-agent`
(agent)। Installer-এর দুটোই এক folder-এ লাগে।

<Tabs>
<TabItem label="আপনার computer-এ build">

`make release` দুটো program-ই Linux-এর amd64 আর arm64-এর জন্য web interface-সহ build করে, আর
প্রতিটাকে installer-সহ একটা archive-এ ভরে দেয়।

<Steps>

1. Source code নামিয়ে release archive build করুন:

   ```bash
   git clone https://github.com/ekPanel/ekpanel.git
   cd ekpanel
   make release
   ```

   এটা প্রথমে web interface-এর জন্য `npm ci` আর `npm run build` চালায়, তারপর Go program-গুলো
   build করে। `dist/`-এ আপনি এ রকম file পাবেন:

   ```text
   dist/ekpanel-<version>-linux-amd64.tar.gz
   dist/ekpanel-<version>-linux-arm64.tar.gz
   dist/SHA256SUMS
   ```

2. আপনার server-এর CPU type-এর archive-টা server-এ copy করুন:

   ```bash
   scp dist/ekpanel-*-linux-amd64.tar.gz root@your-server:
   ```

3. Server-এ এটা unpack করে folder-এ ঢুকুন:

   ```bash
   tar -xzf ekpanel-*-linux-amd64.tar.gz
   cd ekpanel-*-linux-amd64
   ```

   Folder-এ আছে `ekpanel`, `ekpanel-agent`, `install.sh` আর `LICENSE`।

</Steps>

</TabItem>
<TabItem label="Server-এ build">

Server-এ Go 1.27+ আর Node.js 22+ install করলে সেখানেই build করতে পারেন। `make build` যে machine-এ
চলে তার জন্য web interface আর দুটো program build করে।

<Steps>

1. Source code নামিয়ে build করুন:

   ```bash
   git clone https://github.com/ekPanel/ekpanel.git
   cd ekpanel
   make build
   ```

   Program-গুলো এখন `bin/`-এ: `bin/ekpanel` আর `bin/ekpanel-agent`।

2. Installer-টা তাদের পাশে copy করুন:

   ```bash
   cp deploy/install.sh bin/
   cd bin
   ```

</Steps>

</TabItem>
</Tabs>

<Aside type="caution" title="সবসময় web interface build করুন">
`make panel agent` শুধু Go program-গুলো build করে। আগে `make ui` না চালালে (যা `make build` আর
`make release` আপনার হয়ে করে দেয়), panel-এর দেখানোর মতো কোনো web interface থাকে না।
`make panel agent` যে computer-এ চালান তার জন্যই build করে, তাই আপনার computer আর server আলাদা ধরনের হলে
`make release` ব্যবহার করুন।
</Aside>

## Installer চালান

`install.sh`-এর একদম ওপরে লেখা installer-এর ব্যবহার:

```bash
sudo ./install.sh --local-dir DIR [--domain panel.example.com] [--email you@example.com]
```

| Option | মানে |
| --- | --- |
| `--local-dir DIR` | যে folder-এ `ekpanel` আর `ekpanel-agent` program আছে। আপাতত এটা দিতেই হবে। |
| `--domain NAME` | এই server-এর দিকে point করা একটা DNS নাম। Caddy এর জন্য Let's Encrypt-এর একটা free certificate নেয়। |
| `--email ADDRESS` | Let's Encrypt-এর মেয়াদ শেষের notice-এর জন্য আপনার address। ঐচ্ছিক। |
| `-h`, `--help` | ব্যবহারের নিয়ম দেখায়। |

<Tabs>
<TabItem label="Domain-সহ">

```bash
sudo ./install.sh --local-dir . --domain panel.example.com --email you@example.com
```

তখন panel থাকে `https://panel.example.com`-এ, একটা trusted certificate-সহ।

</TabItem>
<TabItem label="Domain ছাড়া">

```bash
sudo ./install.sh --local-dir .
```

তখন panel থাকে `https://<server IP>`-এ, একটা self-signed certificate-সহ। আপনার browser একবার
সতর্ক করবে; এগিয়ে যেতে সতর্কবার্তাটা মেনে নিন। পরে `--domain` দিয়ে installer আবার চালিয়ে
domain যোগ করতে পারেন।

</TabItem>
</Tabs>

শেষে installer এ রকম কিছু দেখায়:

```text
==> ekPanel is installed.
    Open:  https://panel.example.com
    Setup token (needed once, to create the administrator):
        <setup token>
    Agents on other servers connect to TCP port 7443; allow it in any cloud firewall.
    Logs:  journalctl -u ekpanel -u ekpanel-agent -f
```

**Setup token**-টা copy করে রাখুন। পরের ধাপে এটা লাগবে।

## Administrator তৈরি করুন

<Steps>

1. Installer যে address দেখিয়েছে সেটা খুলুন। নতুন panel সরাসরি **ekPanel-এ স্বাগতম** (Welcome
   to ekPanel)-এ যায়।

2. **সেটআপ টোকেন** (Setup token) paste করুন, তারপর **আপনার নাম**, **ইমেইল** আর **পাসওয়ার্ড**
   (অন্তত 10 অক্ষর) পূরণ করুন।

3. **অ্যাডমিন তৈরি করুন** (Create administrator)-এ click করুন। আপনি sign in হয়ে যাবেন, আর
   setup token আর কাজ করবে না।

</Steps>

Setup token নিশ্চিত করে যে আপনার আগে অন্য কেউ আপনার নতুন panel দখল করতে পারবে না। হারিয়ে
ফেললে, যতক্ষণ কোনো administrator তৈরি হয়নি, ততক্ষণ server থেকে এটা পড়ে নিতে পারেন:

```bash
sudo cat /var/lib/ekpanel/setup-token
```

এটা panel-এর log-এও আছে (`sudo journalctl -u ekpanel`)। এখান থেকে এগিয়ে যান
[প্রথম ধাপগুলো](/start/first-steps/)-এ।

## Installer কী করে

`install.sh` আপনি নিজেই পড়ে দেখতে পারেন; প্রায় 270 লাইন। ক্রমানুসারে এটা:

<Steps>

1. **Check করে** যে এটা root হিসেবে, support করা OS আর CPU-তে চলছে (দেখুন
   [যা যা লাগবে](/start/requirements/)), `--local-dir`-এ দুটো program-ই আছে, আর `--domain`
   একটা সাধারণ host নাম।

2. **Package install করে**: `ca-certificates`, `curl`, `gnupg`, `openssl`, `acl` (যাতে web
   server প্রতিটা site-এর file পড়তে পারে, অথচ অন্য site-এর জন্য সেগুলো খুলে দিতে না হয়) আর
   `postgresql`। Ubuntu-তে `software-properties-common`-ও, যা পরে PHP package repository যোগ
   করতে লাগে। Caddy আগে থেকে install না থাকলে সেটা আসে Caddy-র official package repository
   থেকে।

3. **`ekpanel` system user তৈরি করে** (shell ছাড়া), data folder `/var/lib/ekpanel` (শুধু সেই
   user পড়তে পারে) আর `/etc/ekpanel`।

4. **PostgreSQL role আর database `ekpanel` তৈরি করে।** Panel local socket দিয়ে peer
   authentication-এ connect করে, তাই কোনো database password নেই। বাকি সবার জন্য ওই database-এর
   access-ও তুলে নেয়, যাতে customer-দের database account সেখানে connect করতে না পারে।

5. **Program-গুলো install করে** `/usr/local/bin/ekpanel` আর `/usr/local/bin/ekpanel-agent`
   হিসেবে, panel-এর setting লেখে `/etc/ekpanel/panel.env`-এ, আর দুটো systemd unit লেখে:
   - `ekpanel.service` panel-কে `ekpanel` user হিসেবে চালায়, কোনো privilege ছাড়া আর কড়া
     sandbox-এ (read-only system, নিজস্ব `/tmp`, কোনো capability নেই)। Server-এ কাজ করে
     agent, panel না।
   - `ekpanel-agent.service` agent-কে root হিসেবে চালায়, কারণ এটাই server চালায়।

6. **Panel চালু করে**, আর `http://127.0.0.1:8080/api/v1/health`-এ সাড়া দেওয়ার জন্য 30 সেকেন্ড
   পর্যন্ত অপেক্ষা করে। প্রথমবার চালু হওয়ার সময় panel তার database table, agent-দের জন্য নিজস্ব
   private certificate authority, তার secret key আর setup token তৈরি করে।

7. **এই server-এর agent connect করে।** Server-টাকে তার host নামে register করে
   (`ekpanel add-server` দিয়ে), agent-কে `127.0.0.1:7443`-এ enrol করে, আর `ekpanel-agent` চালু করে।
   Agent আগে থেকেই enrolled থাকলে এই ধাপ বাদ যায়।

8. **Caddy configure করে** `/etc/caddy/Caddyfile`-এ: আপনার domain-এ বা server-এর address-এ
   panel, `/etc/ekpanel/caddy/sites/*.caddy`-এর একটা import (প্রতিটা website-এর জন্য একটা file,
   agent লেখে), আর Cloudflare-এর publish করা address range-গুলোকে trust, যাতে Cloudflare-এর
   পেছনে থাকলেও log-এ visitor-দের আসল address দেখা যায়। Configuration check করে Caddy reload
   করে।

9. **ufw-এ port 80, 443 আর 7443 খোলে**, শুধু ufw আগে থেকে চালু থাকলে।

10. **দেখায়** address, setup token আর log কোথায় আছে।

</Steps>

## Panel-এর HTTPS কীভাবে কাজ করে

| | `--domain`-সহ | `--domain` ছাড়া |
| --- | --- | --- |
| Certificate | Let's Encrypt, Caddy নেয় আর renew করে | Self-signed, installer বানায়, 825 দিন চলে |
| Panel-এর address | শুধু `https://<your domain>` | `https://<server IP>`, `https://<host name>`, `https://localhost`, `https://127.0.0.1` |
| Browser-এর সতর্কবার্তা | না | একবার, যতক্ষণ না আপনি মেনে নেন |

পরে যোগ করা website-গুলো নিজেদের certificate পায়; panel-এর certificate শুধু panel-এর জন্য।

<Aside type="caution">
Let's Encrypt certificate দিতে পারে শুধু তখনই, যখন domain এই server-এর দিকে point করা আর
internet থেকে port 80 আর 443-এ পৌঁছানো যায়। ততক্ষণ panel-এর address-এ certificate error দেখায়।
DNS record বা cloud firewall ঠিক করুন, Caddy নিজে থেকেই আবার চেষ্টা করবে।
</Aside>

## সমস্যা হলে

- **"is not supported yet"**: OS বা CPU support তালিকায় নেই। amd64 বা arm64-এ Ubuntu 24.04+ বা
  Debian 12+ ব্যবহার করুন।
- **"release downloads are not available yet"**: আপনি `--local-dir` দেননি। দুটো program যে
  folder-এ আছে সেটা দিন (সেই folder-এ থাকলে `--local-dir .`)।
- **"not found or not executable"**: folder-এ একটা program নেই, বা তার executable bit হারিয়ে
  গেছে। `chmod +x ekpanel ekpanel-agent` চালান।
- **"the panel did not start"**: `sudo journalctl -u ekpanel` দিয়ে panel-এর log পড়ুন।
- **Page load হয় না**: আপনার provider-এর firewall-এ port 80 আর 443 খোলা আছে কি না দেখুন।
- **"The web UI has not been built into this binary"**: panel web interface ছাড়া build করা
  হয়েছে। `make release` বা `make build` দিয়ে আবার build করুন, আর installer আবার চালান।

আরও আছে [সমস্যা সমাধান](/reference/troubleshooting/)-এ।
